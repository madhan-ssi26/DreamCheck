# First-use review

This was a fresh Chrome profile review using saved runs and datasets from the development workstation. It exercises the browser workflows. An independent Dream-1 user still needs to try the app without coaching.

| Workspace | What was easy to follow | Where I had to stop and think |
| --- | --- | --- |
| Home and quick guide | The primary Judge button stood out. The replay let me step through the two arms quickly. | The guide originally asked for a saved timeout before explaining how to create evidence. It now opens an offline relay setup and puts focus on the reference button. |
| Judge | The verdict, camera views, and timeline make the incomplete stage visible. The verdict links to request timing. | The camera cards are samples prepared by the client. Understanding what a reply confirms requires reading the supporting text. The prompt preset also used to silently change the scene, checkpoint, and timing. It now edits only the prompt. |
| Compare | The paired images and pass counts are useful after a comparison finishes. | A new user has to understand baseline, candidate, and matching before starting a live comparison. The saved result makes those terms concrete. The live demo starts from that result. |
| Run History | Searching for “transfer plate” finds relevant saved runs. | Similar prompts are hard to distinguish until you read their scene and outcome. |
| Scene import | The Workshop example and goal footprint show what is being configured. | Collapsing the goal editor used to clear the goal. An explicit scoring checkbox now controls that state. |
| Recording import | Pick a camera, seek the video, and bookmark a moment. Export contained the requested frame and nearby telemetry. | Folder conventions and the JSON export assume familiarity with LeRobot and telemetry. The recording guide includes a concrete file tree. |
| Fine-tune | Validation counts, job progress, and the relay failure breakdown are useful once a dataset is selected. | A single latest-dataset view obscured earlier jobs. There is now a dataset picker so the apple, relay, and sorting bundles can be reviewed separately. |

For a short outside-user check, open a real timeout and ask the participant to identify the first incomplete stage, find the reply count, and explain what their retry changes. Observe whether they can complete all three without coaching.
